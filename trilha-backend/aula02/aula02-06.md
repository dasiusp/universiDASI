## STRING
Mas o que tem de tão especial em um texto? Bem, a String não é só um texto e sim um OBJETO! Uma String é usado para manipular o sequências de caracteres, praticamente funcionando como um array de caracteres.

Aqui vamos ver alguns métodos de String.

### .charAt(posição)
Pega um caracter em uma posição.
```js
const texto = "Agora";
console.log(texto.charAt(0)); // = "A"
``` 

### .toUpperCase()
O texto é escrito em caixa alta.
```js
const texto = "texto";
console.log(texto.toUpperCase()); // TEXTO
console.log(texto); // texto
```

### .toLowerCase()
O texto é escrito em caixa baixa.
```js
const texto = "TEXTO";
console.log(texto.toLowerCase()); // texto
console.log(texto); // TEXTO
```

### .concat(texto1, texto2, ...)
Ele concatena uma String com N Strings.
```js
const string = "Texto1";
console.log(string.concat("Texto2", "Texto3")); // Texto1Texto2Texto3
console.log(string); // Texto1
```

### .replace(palavraQueVaiSubstituir, palavraNova)
Esse método vai substituir uma palavra, sua primeira ocorrência da String por outra.
```js
const string = "Aprendendo Python e Python 3!";
console.log(string.replace("Python", "Javascript")); //Aprendendo Javascript e Python 3!
console.log(string); //Aprendendo Python e Python 3!
```

### .replaceALL(palavraQueVaiSubstituir, palavraNova)
Esse método vai substituir todas as instâncias da palavra da String por outra.
```js
const string = "Aprendendo Python e Python 3!";
console.log(string.replace("Python", "Javascript")); //Aprendendo Javascript e Javascript 3!
console.log(string); //Aprendendo Python e Python 3!
```

### .slice(init, end)
Ele faz uma fatia de uma String. Ele tem farias formas de fazer esses fatiamente:
```js
const texto = "Isso é para ser um texto muito longo ou algo muito próximo.";

// .slice(30) => ele vai começar da 31° posição da String e vai até o final
console.log(texto.slice(30)); // " longo ou algo muito próximo."

// .slice(30, 40) => ele vai começar da 31° posição e termina da 41°
console.log(texto.slice(30, 40)); // " longo ou "

// .slice(-4) => ele vai pegar a última posição, voltar quatro e ir dessa posição até o final
console.log(texto.slice(-4)); // "imo."

// .slice(-9, -5) => vai começar da última poisçã menos 9 e ir atá a última posição -5.
console.log(texto.slice(-9, -5));// " pró"
```

### .split(texto)
O split vai dividir a String onde está escrito o texto e vai retornar um array dessa divisão.
```js
const logradouro = "Rua Mariana, N° 128, Jardim Bar, Brás, São Paulo";
const listaLogradouro = logradouro.split(", ");
/*
Resultado:
listaLogradouro = ["Rua Mariana", "N° 128", "Jardim Bar", "Brás", "São Paulo"];
*/
```

### .trim()
Esse método é responsável por tirar espaços em branco no final e no começo de um String.
```js
const texto = "    Espaço atrás e na frente    ";
console.log(texto.trim()); // "Espaço atrás e na frente"
console.log(texto); // "    Espaço atrás e na frente    "
```

De métodos de String, esses são os mais usados, mas existem diversos outros que você pode conferir na documentação do Javascript.
