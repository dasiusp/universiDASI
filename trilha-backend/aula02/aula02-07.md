## Métodos de Array
Aqui vamos abordar mais sobre os métodos dos arrays, ou seja, funções padrões que dá para usar no array.

Uma coisa interessante é que a maioria dos métodos funcionam em uma String, pois ambos são uma estrutura que apresenta uma sequência de valores.

### .length
Não é um método, MAS é usado muito. O `.length` retorna a quantidade de elementos contidos dentro da lista.

```js
const texto = "Isso é um texto";
const lista = [1, 2, 3, 4, 5];
console.log(texto.length); // 15
console.log(lista.length); // 5
```

### .slice (igual à string!)
Exatamente, assim como String, faz uma fatia da lista, com as mesma regras que uma String.
```js
const comida = ["Abacaxi", "Maçã", "Banana", "Macaco"];
console.log(comida.slice(2)); // ["Abacaxi", "Maçã", "Banana"];
console.log(comida.slice(2,3)); // ["Banana", "Macaco"]
console.lgo(comida.slice(-4)); // ["Macaco"];
console.log(comida.slice(-2, -3)); // ["Maça", "Banana"]
```
