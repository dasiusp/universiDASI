# Introdução ao Backend com Node.JS
Olá meus queridas e queridos! Este repositório tem como objetivo ensinar os iniciantes em programação em como desenvolver um backend básico.
Mostraremos ferramentas principais usado para o desenvolvimento e teste do backend.

As aulas desse repositório é montadas em 4 aulas + um resumo:

## [Resumo](./resumo.md)
Aqui tem o resumo de todas as aulas em um única arquivo.

## [Aula 00 - Conhecendo a Internet](./aula00/)

Você já se perguntou como a Internet chega na sua casa? Como você acessa o Youtube? Esta aula acaba por mostrar o básico que você precisa saber para entrar nesse mundo.

## [Aula 01 - Instalação do Visual Studio Code e Node.js](./aula01/)
Agora vamos limpar o nosso terreno e ajeitando o solo para construir nosso backend. Nesta aula, baixaremos o Visual Studio Code e Node.js para podemos fazer nossos pequenos projetos.

## [Aula 02 - Básico de Javascript](./aula02/)
Aqui vai reabordar o básico de Javascript para não ficar perdido durante o desenvolvimento.

## [Aula 03 - Básico de Backend](./aula03/)
Agora começamos a brincar jejeje! Começamos a ver o básico para um backend funcionar e suas operações mais básicas.

## [Aula 04 - Rotas, Controladores, **Middlewares** e *Models*](./aula04/)
Como podemos deixar mais organizados o projeto? Esta aula aborda as três divisões mais básicas para a criação de um backend, usando em diversos sitemas.

## Orientações
Siga as aulas em ordem e não pule-as! Cada conteúdo anterior é usado posteriormente, principalmente a aula 04, que já assume que você dominou o conteúdo da aula 03, para não ficar enrrolando e mostrar na prática.

## Requisitos
- Lógica de programação;
- Básico de Javascript;
- Força de vontade e coragem (kkkk).

## Diferenciais
- Programação Orientada à Objetos (isso é um tópico interessante para melhor organização de código, importante para projetos grandes)
